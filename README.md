## Getting started with Copilot

The best way to get started with Copilot is to use it inside your editor while working on a small, real task.

1. Install GitHub Copilot in your editor, such as VS Code.
2. Sign in with your GitHub account and enable Copilot.
3. Open a project and start by writing a comment, function name, or simple prompt.
4. Review the suggestion, accept what helps, and edit it to match your needs.
5. Ask follow-up questions in Copilot Chat to learn, refactor, test, or explain code.

Start small, verify each suggestion, and treat Copilot as a coding partner rather than an autopilot tool.
